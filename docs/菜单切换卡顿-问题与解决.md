# 菜单切换卡顿 / 标签页未及时跳转 — 问题说明与解决

## 1. 现象

- 点击侧栏后选中态滞后、标签切换像没反应。
- Performance 出现 500ms+ Long Task；切回已打开页仍重建表格、重复请求。

## 2. 根因

1. **KeepAlive 未包页面**：只挂了 `AliveScope`，路由出口没有 `<KeepAlive>`，切标签等于整页重挂。
2. **菜谱表过重**：默认 50/最大 500 行 + 封面图 + 多 Tag，同帧 Scripting 拖死 paint。
3. **`Suspense fallback={null}`**：懒加载期间无反馈。

侧栏 `selectedKeys` 跟 `location` 走是 antd + React Router 的常规写法；高亮「慢」主要是主线程被页面渲染占满，不是缺一套乐观高亮状态机。

## 3. 已做改动（保持简单）

| 项 | 做法 | 文件 |
|---|---|---|
| 真正 KeepAlive | `GuardedPage` 按 `getTagScopedKey` 包 `<KeepAlive>` | `src/router/index.tsx` |
| 首屏反馈 | `Suspense` / 权限等待用 `Spin` | 同上 |
| 列表减负 | 默认 25；`virtual`；`scroll.x` 数字；图片 lazy；标签单行 | `src/pages/Recipe/list/index.tsx` |
| 侧栏 | `selectedKeys` 跟路由；`defaultOpenKeys` | `src/layouts/BasicLayout/index.tsx` |
| 列表筛选 | 菜谱列表改为 Form `name` + 提交写 `query`（对齐 AdminAccount） | `src/pages/Recipe/list/index.tsx` |
| 食材表单 | `IngredientRows` 改为 `Form.List` | `src/pages/Recipe/components/IngredientRows.tsx` |

**刻意不做**：`NavPending` / `menuIntent` 等乐观高亮层。官方 Menu 示例与多数中后台都是选中态跟路由；卡顿应靠少渲染、缓存页解决，而不是再套一层意图同步。

## 4. 验证

1. 切到菜谱列表再切走再切回：不应整表重建级 Long Task；无故重新打列表接口。
2. 侧栏高亮与当前路由一致；直达/点击进入 `/admin/*` 时父级可展开。
3. 关详情标签后 `drop` 缓存，再开会重新请求。

## 5. 备注

- `import { KeepAlive } from 'react-activation'`（具名导入）。
- 图标由 `unplugin-auto-import` 注入，无需手写 `@ant-design/icons` import。
